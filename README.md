# Food Delivery Analytics (Python + SQL + DuckDB + Streamlit)
This project is an end-to-end **food delivery analytics** pipeline built on a public Kaggle dataset of delivery orders.
It simulates what a data engineer / data analyst might do for a food delivery startup:
- Ingest raw CSV data of orders  
- Clean and transform it with Python  
- Load it into DuckDB for SQL analysis  
- Build a small Streamlit dashboard for visualizations

## 🔍 Dataset

The project uses a public food delivery dataset (10,000+ orders) downloaded from Kaggle.
After downloading, save the main CSV as:
`data/raw/orders_raw.csv`

> Note: The raw dataset is not included in the repo.  
> Please download it yourself and keep the file name as `orders_raw.csv`.

## 🧱 Tech Stack

- **Python** (pandas, pathlib)
- **DuckDB** (embedded analytics SQL engine)
- **Streamlit** (dashboard)
- **CSV files** for raw and processed data
